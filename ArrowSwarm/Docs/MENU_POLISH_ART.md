## Açık tema üretim istemi
Create ONE production-ready transparent PNG sprite atlas for a Unity mobile game Arrow Swarm. Use reference 1 (MainMenuTextless) as the EDIT TARGET STYLE: recreate ONLY its pale icy white GAME MODE capsule button (the one directly below big Play). Reference 2 (ModeButtonAtlas) is ICON REFERENCE for the three different mode illustrations. Output ONLY three horizontally wide capsule buttons stacked vertically, identical sizes/shapes, aligned in three equal-height rows, generous transparent gaps, no other artwork, NO LETTERS, NO WORDS, NO NUMBERS. Each button has width:height approx 4.2:1. Clean smooth glossy cobalt blue and cyan double rim, soft pale ice-white to pale blue interior, subtle outer shadow. Preserve the original main menu button's right thin cyan divider near 85% width and dark blue downward chevron near 92% width. Leave middle from 43% to 81% width completely blank for live localized text. At left 7% to 37% width: ROW 1 Defense icon: cute blue and pink arrows travelling along a white curving dotted path, three small red hearts, shiny blue shield, tiny gold sparkle, matching the reference. ROW 2 Shapes icon: colorful small shiny blue/pink/green/yellow arrows forming an unmistakable heart, tiny sparkles. ROW 3 Color Shift icon: shiny rounded square with cyan top, green left, pink right, yellow bottom and blue center containing a white upward diagonal arrow and small curved rotation arrow. Keep icons inside capsule, beautifully readable at mobile scale. Consistent glossy illustrated 3D casual game UI aesthetic. Uniform capsule geometry and white interior across all three rows. Surrounding canvas is genuine transparent alpha, no backdrop, no cream padding. The result is a single atlas, with three buttons, nothing else.
