# No-Freeze Defense series narration

The eight new public Turkish lines in `defense_series_voice.py` were synthesized
with the existing Microsoft `tr-TR-AhmetNeural` voice at `+8%` using `edge-tts`.
Only those creative sentences were sent; no gameplay capture, account cookies,
player state, private file or credential was sent to the speech service.

Generic R2 approach, calm, sequential-send, Rainbow, clean-sweep and promotional
CTA clips are copied byte for byte from the approved narration library. The
Freeze line is deliberately excluded. The corrected-P CTA SHA256 remains
`3cffc7f86966e7eb7c4c6e7b0524ea7a2ed59c9c013ad2305cfe0adc857e4c23`.

The new raw MP3s and conservatively edge-trimmed 48kHz mono PCM16 WAVs are retained.
`voice_manifest.json` records exact sentences, source paths, durations and hashes;
`voice_QA.json` verifies format and absence of clipped PCM samples. Each episode's
`audio_timeline.json` records actual edit placement and reused project SFX/music.

This is editorial narration and sound reconstruction, not Unity AudioListener
capture. The clean-sweep line is used only with a strict source proof showing all
spawned enemies killed by projectiles, zero victory-cleanup kills and zero path
finishes. The Tip explanation is restricted to the episode with a real charged
hint and its highlighted arrow. No Freeze speech or SFX appears in the series.

Technical checks do not claim subjective listening or user creative approval.
