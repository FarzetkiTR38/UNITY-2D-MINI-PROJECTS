# Kalıcı yaratıcı referans arşivi

Kullanıcının gönderdiği referanslar burada konuya göre saklanır. Dosyalar referanstır; kendi oyunumuzun görüntüsü veya yeniden yayınlama izni olarak sunulmaz.

- [Video referansları ve analiz](Videos/README.md)
- `Store/`: kullanıcı daha sonra mağaza görsellerini gönderdiğinde özgün dosya, kaynak ve istenen uyarlama notları burada tutulacak. Henüz görsel gönderilmedi.

Yeni referans eklerken özgün bağlantıyı/adı, alınma tarihini, gerçekten kaydedilen dosyaları, erişim sınırını ve kullanıcının amaçladığı uyarlamayı manifest'e yaz. Eski sürümleri üzerine yazma.
