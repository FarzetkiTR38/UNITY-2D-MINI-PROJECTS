# Whole-game graphical baseline

The original source Unity Editor was started through BootScene, then the existing paired-theme capture fixture visited thirty visible screen states. Six montages preserve every actual Light/Dark screen at review size. The eight original pause PNGs retain full-resolution evidence of the Turkish title overflow in Defense, Shapes, Color Shift and MapTest.

`capture-report.txt` records every native capture and exact Light restoration. The isolated provider report confirms zero real cloud operations. `scene-audit.json` inventories all six enabled scenes and their pause title dimensions; `missing-reference-audit.json` additionally checks 4,696 serialized components and reports no broken object references.

Montages are resized arrangements of actual game renders, not proposed artwork. Remaining original PNGs are retained in the task's local evidence archive rather than duplicating every native render in Git. The follow-up verification folder contains the changed screens after repair.
